# SEO audit helpers

This folder is for manual verification only.

Google Search Console should use the real root sitemap:

```text
https://wizarding-archive-sumit.netlify.app/sitemap.xml
```

`robots.txt` also points to that root sitemap. Do not submit the reference copy in this folder to Search Console; it exists only so you can compare the deployed sitemap contents after changes.

Files:

- `sitemap-reference.xml` - reference snapshot of the current root sitemap.
- `search-page-template.md` - reusable checklist/template for future search-focused Harry Potter guide pages.
