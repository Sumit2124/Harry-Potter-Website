# Contributing to The Wizarding Archive

Thank you for helping improve this fan project.

## Before opening a change

- Keep the site static and dependency-free unless a change genuinely needs a service.
- Use the existing visual language: midnight blue, warm gold, readable body text, and restrained magical motion.
- Make every new page mobile-friendly and keyboard-accessible.
- Add a unique title, meta description, canonical URL, and one focused topic to new guide pages.
- Add useful internal links and update `sitemap.xml` for every new crawlable page.

## Local check

```bash
python3 -m http.server 4173
```

Then inspect the affected route at desktop and mobile widths. Confirm there is no horizontal overflow, broken image, empty query-parameter route, or console error introduced by the change.

This is an unofficial fan project. Please do not add private credentials or redistribute copyrighted media.
